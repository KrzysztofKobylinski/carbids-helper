# bid.cars Helper

Chrome extension that adds two actions next to the favorite heart on [bid.cars](https://bid.cars) listings:

- **Hide listing** (eye-slash) — shadows offers you are not interested in so they disappear from search results
- **Mark opened** (checkmark) — flags lots you already looked at; opening a lot page also marks it automatically

Hidden listings can be revealed with **Show shadowed** in the in-page toolbar or the extension popup.

## Install (unpacked)

1. Open `chrome://extensions`
2. Turn on **Developer mode**
3. Click **Load unpacked** and select this folder
4. Open a bid.cars search page — the new icons appear next to the heart
